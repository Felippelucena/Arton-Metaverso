# Arton Metaverso
Gerenciador de Partidas de Tormenta20

Bem-vindo ao **Arton Metaverso**, um webapp de código aberto desenvolvido para gerenciar partidas de Tormenta20. Este projeto é construído com WordPress e inclui funcionalidades específicas para ajudar mestres e jogadores a gerenciarem suas aventuras de forma eficiente.

## Descrição do Projeto

O **Arton Metaverso** é um plugin que expande as capacidades do WordPress, oferecendo uma interface para gerenciar personagens, rolar atributos e organizar sessões de RPG baseadas nas regras de Tormenta20. O projeto é open-source, e qualquer pessoa pode contribuir ou usar para gerenciar suas próprias partidas.

## Funcionalidades Principais

- Gerenciamento de personagens
- Rolagem de atributos com lógica de distribuição
- Interface amigável para jogadores e mestres
- Personalização e expansão com base nas regras de Tormenta20

## Instalação e Execução Local

Siga os passos abaixo para configurar o projeto localmente utilizando o **LocalWP**.

### Pré-requisitos

- **LocalWP**: Ferramenta para desenvolvimento local de sites WordPress. [Baixe aqui](https://localwp.com/).
- **Arquivo ZIP do projeto**: Disponível na branch `main` deste repositório.

### Passos para Instalação

1. **Instale o LocalWP**:
   - Baixe e instale o LocalWP em sua máquina.
   - Crie um novo site no LocalWP com configurações padrão de PHP e banco de dados.

2. **Importe o arquivo ZIP do projeto**:
   - Faça o download do arquivo ZIP da branch `main` deste repositório.
   - No LocalWP, clique no botão **"More" (Mais)** ao lado do site criado e selecione **"Open Site Shell" (Abrir Shell do Site)**.
   - Importe o arquivo ZIP pelo painel do WordPress ou descompacte manualmente os arquivos na pasta `wp-content`.

3. **Ative o plugin**:
   - Acesse o painel de administração do WordPress em `http://nome-do-seu-site.local/wp-admin`.
   - Vá para **Plugins** > **Adicionar Novo** e ative o plugin **Tormenta20 Manager**.

### Configuração Adicional

- **Instale Dependências**: Certifique-se de que todas as dependências do WordPress e de plugins necessários estejam ativas.
- **Sincronize a branch `develop`**: Se você deseja modificar o plugin diretamente, utilize a branch `develop`, onde estão os arquivos do plugin core.
